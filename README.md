Image Processing using Python & OpenCV

About the Project

This project demonstrates fundamental image processing techniques using Python, OpenCV, NumPy, and Matplotlib in Google Colab.

Features

* Image upload and loading
* Image dimensions analysis
* RGB channel extraction and visualization
* Grayscale conversion
* Image thresholding
* Gaussian blurring
* Canny edge detection
* Image resizing
* Image rotation
* Image flipping
* Saving and downloading processed images

Technologies Used

* Python
* OpenCV
* NumPy
* Matplotlib
* Google Colab

How to Run

1. Download the .ipynb notebook from this repository.
2. Open Google Colab.
3. Upload the notebook.
4. Run the code cells sequentially.
5. Upload an image when prompted.
6. View and download the processed images.

Learning Outcomes

Through this project, I practiced image manipulation, RGB channel extraction, grayscale conversion, thresholding, filtering, edge detection, and basic computer vision operations.
